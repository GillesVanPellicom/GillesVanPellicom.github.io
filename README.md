# Portfolio

## Hybride SAT-solver
Ontwikkeld een <a href="https://github.com/GillesVanPellicom/hybrid_SAT/tree/main?tab=readme-ov-file#sat-sandbox">geavanceerde versie van een DPLL SAT-solver in C++</a> met een combinatie van low-level optimalisaties en slimme heuristieken om de rekentijd en efficiëntie aanzienlijk te verbeteren. 
Het project richtte zich op het identificeren en implementeren van prestatieverbeteringen in een complexe, algoritmische context.

Daarnaast is <a href="https://github.com/GillesVanPellicom/hybrid_SAT/blob/main/docs/Summary.pdf">een paper</a> opgemaakt waarin de impact van deze optimalisaties werd geanalyseerd, met een focus de optimalisaties zelf.
De solver fungeerde eerder als een testplaats voor optimalisatie van geadvanceerde algorithmes.

## n-Queens Puzzel-solver
Ontworpen van <a href="https://github.com/GillesVanPellicom/CodingProblems_2024/tree/main/src/CodeWars/n-Queens">een solver</a> voor een variant van het <a href="https://en.wikipedia.org/wiki/Eight_queens_puzzle">8-queens probleem.</a>

Eigen extensie ontworpen van de heuristiek min-conflicts, zorgt voor exponentiele speedup.

<a href="https://github.com/GillesVanPellicom/CodingProblems_2024/blob/main/src/CodeWars/n-Queens/Solution.pdf">Researchpaper geschreven over extensies.</a> Geen baanbrekend onderzoek en eerder een iteratieve verbetering, maar desalniettemin nieuw onderzoek.

## Verkeerssimulator
